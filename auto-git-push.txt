Production deploy

Remote (already added on this machine):
  production  server_admin@172.16.2.9:~/repos/personel_management_app.git

Push only committed work on main:
  git push production main

What that does
  The bare repo is ~/repos/personel_management_app.git and its HEAD is main.
  The post-receive hook checks out main into
  /home/server_admin/personel_management_application, installs from the
  repo root with --ignore-scripts (so Electron is not downloaded), builds
  the shared package, generates the Prisma client, compiles packages/server,
  and restarts PM2 app personel-management-server.

Server runtime
  The hook puts nvm Node 24.21.0 on PATH. Prisma 7 does not support
  Node 23. PM2 itself stays the Node 23 install, because that is the
  daemon already running the other apps. This API is started from
  ~/pm2/ecosystem.config.cjs, which pins the interpreter to Node 24. Boot still runs `nvm use v23.11.1` for the
  other apps; this process keeps its own interpreter.
  packages/server/.env stays on the server (it is gitignored).
  DB_TARGET=prod, and PORT=4000 so it matches the desktop
  SERVER_URL_PROD (http://172.16.2.9:4000).

The hook source in this repo is deploy/post-receive. After editing it,
copy it to the bare repo and keep it executable:
  scp deploy/post-receive server_admin@172.16.2.9:~/repos/personel_management_app.git/hooks/post-receive
  ssh server_admin@172.16.2.9 chmod +x ~/repos/personel_management_app.git/hooks/post-receive
